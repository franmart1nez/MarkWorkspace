# Total (in)Sanitation · Stage 5 signage

Twelve editable SVGs cover the ten selected Basement signs, Wet Floor and A Clean Start to Every Shift. Each SVG contains its graphics and editable English lettering. `catalog.json` records the original proposal, approved mascot master where used, lettering, dimensions and checksums. Paths in the catalog are relative to the Total (in)Sanitation Workspace folder.

- Chemical Spill uses the approved Acid on the floor silhouette. The master contains the spill and steam.
- Cleaning Equipment uses the approved Pushing equipment silhouette.
- Wet Floor reuses the approved slipping-pose artwork in the existing SVG and retains the original PNG exported from that master.
- A Clean Start uses the approved Greeting silhouette in the revised orange-circle and three-stripe layout.

Use **Bahnschrift Bold**, **Impact** and **Arial Black** to match the reviewed Windows exports. Each line remains a text object with its own placement. After translation, refit long lines to their panel and verify the raster export at the intended size. The masters use editable vector fills and simplified rim wear, with the original PNGs retained in the Workspace review.
