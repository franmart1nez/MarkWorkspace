# Wizard mascot / SVG traces v04

Four owner-selected hazard poses traced by Adobe and consolidated into editable, single-ink compound paths. Each pose has black and white masters with identical geometry, transparent cutouts, and the original 1254-square framing. The original Adobe paths are in adobe-originals.

Each color is exported as a transparent PNG at 32, 48, 64, 96, 128, 256, 512 and 1024 px. The three review sheets show source fidelity, light/dark/yellow backgrounds, and actual display sizes. View the size sheet at 100%. The manifest records raster SHA-256 hashes, measurements and per-size alpha checks.

The electrical accident has five digits on each hand. Other wizard poses are in the v02 and v03 deliveries and the complete stage-4 library.
