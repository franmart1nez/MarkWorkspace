# Sculpture Colorization instructions

Read `START_HERE.md`, `DIRECTIVES.md`, `GENERATION_POLICY.md`, `NEXT_SESSION.md`,
`project.json` and the selected sculpture's manifest, handoff and brief before
production. Use the repository's image-reference and Workspace authoring skills;
the project-specific sequence in `DIRECTIVES.md` takes priority.

- Composite 01 arrives finished and is the supreme appearance reference.
- The only other appearance references are shared client-approved quality examples.
- Every target's original PSD remains its geometry/camera authority.
- Start with the remaining input views. Plan a small size-dependent crop set
  directly from each source; no preliminary full-image generation or 01 approval gate.
- Generate and review all required crops for all target views before assembly.
- Announce batch crop readiness, ask the user to open Photoshop if closed and
  verify the native connection and exact document before editing.
- Assemble only in Photoshop, sequentially, with editable layers/source masks.
  No manual color/lighting corrections or warping. Reopen and verify each PSD/PSB.
- Use the highest available ChatGPT image quality under `GENERATION_POLICY.md`.
  Apply supported live controls; distinguish requested from actual settings.
  Magnific requires an explicit request. Respect budgets and recover existing jobs.
- Keep original sources untouched and all work in the user-selected sculpture.
  Empty folders are not assignments; do not resume another sculpture automatically.
- Configuration/readiness work does not authorize generation or application restarts.
