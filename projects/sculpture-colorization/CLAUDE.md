# Sculpture Colorization entry point

Read `AGENTS.md`, `START_HERE.md`, `DIRECTIVES.md`, `GENERATION_POLICY.md`,
`NEXT_SESSION.md` and the selected sculpture's manifest/brief. On-disk files are
authoritative. Respect the user's selected agent, model, permissions and budget.

Composite 01 is supplied finished. Use it as the highest appearance reference,
with shared quality examples. Start directly with low-count size-based crops
from all remaining target PSDs. Finish and review the whole crop batch before
asking the user to open Photoshop. Assemble each view sequentially in Photoshop
and verify saved editable files. See `PHOTOSHOP_INTEGRATION.md` for the local MCP
and the direct client usable without restarting a running agent session.

A client without native ChatGPT image generation prepares a handoff to a capable
session; it does not switch automatically to a separately billed provider.
Configuration work does not authorize generation or application restarts.
