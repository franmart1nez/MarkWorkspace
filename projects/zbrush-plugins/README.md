# ZBrush plugins - Render/ID 3.2.6 + Fast 0.3

**Camera Bank Fast is the only active camera writer.** The Render/ID package no longer contains the old Camera Bank folder, binary, launcher or camera installation option. Its installer backs up and retires explicit old installed writer files while preserving Fast, saved banks and unrelated plugins.

**IMPORT VWS** adds native ZAppLink views to free Fast slots with Render ON. It reads the 320-byte, eight-view layout and converts positions using the current document dimensions. Lens and visibility start from the current session. **Desactivar todas las camaras** and **Activar todas las camaras** sit above the numbered slots and set the Render flag for all stored cameras. To adjust a view, recall it and press **UPDATE ACTIVE** after editing. Save the matching model and export the bank.
