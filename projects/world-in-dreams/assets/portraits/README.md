# Portraits

Optional. Put a square image named after a species id here (for example
`human.png`, `elf.png`, `catfolk.png`) and the person card in the viewer shows
it instead of the coloured disc. Species ids are the keys of `SPECIES` in
`src/engine/people.js`: `human`, `catfolk`, `elf`, `dwarf`, `halfling`,
`foxfolk`.
